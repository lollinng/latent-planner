How it works

A world model is a network that answers “if I take this action, what happens next?”. A language model predicts the next token from the tokens so far; a world model predicts the next state of a world from the current state and an action. Nobody told this one where the walls are or where the dot is. It only watched 98,000 frames of the dot wandering at random.

  1. Learn. An encoder (like the encoder half of an encoder–decoder) turns each 64×64 frame into 32 numbers, its embedding. A small predictor learns to guess the next frame's embedding from the current embedding and the action. There is no decoder: it never draws pictures, it only predicts embeddings. That invites a lazy shortcut, giving every frame the same embedding so prediction is trivially perfect (“collapse”), so a second loss term, SIGReg, keeps the embeddings spread out like a bell curve. Without it, planning succeeds 6% of the time instead of 100%.
  2. Imagine. To choose a move, the browser guesses 300 action sequences and uses the predictor to imagine where each one leads, 20 steps ahead, entirely in embedding space.
  3. Choose. It keeps the sequences whose imagined end lands closest to the goal picture's embedding, guesses again around those, and repeats 10 times (the cross-entropy method). It executes the first 4 steps of the best plan, looks at the new frame, and plans again, like a GPS recalculating. There are no rewards and no trained policy: just a learned simulator and search.

The dotted path is decoded with a linear read-out fitted after training, only to draw it; the planner never sees positions. Turn on the cost map to see what the planner optimises: distance in embedding space is a sharp basin around the goal with only a weak slope beyond it, not a map of the rooms. Routes through the door come from the model knowing walls block it and imagining far enough ahead to find the basin.

Environment, model and planner are written from scratch for this demo. Objective: LeWM (Maes et al.) and LeJEPA's SIGReg (Balestriero & LeCun, 2025). Code and write-up.
